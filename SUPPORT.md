# Facet Review support

## Before opening an issue

1. Confirm Node.js 22.14 or newer with `node --version`.
2. Run `facet doctor` and keep its non-sensitive output.
3. Reproduce the issue with the smallest artifact possible.
4. Check that the same `--data-dir` is used for all commands in one session.

## Ask for help

Use [GitHub Issues](https://github.com/VishalMakwana23/facet-review/issues) for installation problems, defects, compatibility reports, and feature requests. Include the Facet version, operating system, Node version, command used, expected result, and actual result.

Do not include secrets, private review content, personal information, or a complete session store in a public issue.

Report vulnerabilities privately by following [SECURITY.md](SECURITY.md).
