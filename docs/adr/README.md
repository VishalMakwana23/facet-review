# Architecture Decision Records

Architecture decisions are immutable records. Supersede an accepted ADR with a new record instead of rewriting its outcome.

## Template

```markdown
# ADR-NNNN: Title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Owners: names or roles

## Context
What decision is required and which constraints matter?

## Decision
What is the chosen direction?

## Consequences
What becomes easier, harder, mandatory, or explicitly deferred?

## Verification
Which evidence proves the decision is being followed?
```
