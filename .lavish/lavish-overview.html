Visual collaboration layer

Turn an agent’s answer into a page you can see, inspect, and comment on.

Lavish is a CLI-powered review surface for agent-generated HTML. It is especially useful for plans, comparisons, diagrams, tables, reports, code reviews, prototypes, and presentations.

How it works

A visual review loop, not just a prettier answer

The agent builds a standalone HTML artifact, Lavish serves it locally in a browser, and your annotations return as actionable feedback.

Why use it

The practical benefits

1

Faster understanding

Hierarchy, diagrams, tables, and side-by-side views reduce scanning effort.

2

Precise feedback

Annotate the exact element or selected text instead of describing where the issue is.

3

Iterative review

Your comments return to the agent, which can revise the artifact and reopen the loop.

4

Portable output

Export a standalone HTML file with local assets inlined for later viewing.

What Lavish does not do

  • 01It does not improve reasoning automatically. It improves how complex work is presented, inspected, and revised.
  • 02It is not necessary for every answer. A short explanation or simple command is usually better directly in chat.
  • 03It does not inject a design system. The agent must match your project’s styles or deliberately choose a fallback.
  • 04Remote resources stay remote. An exported page inlines local assets, but CDN fonts or scripts still require network access.

Privacy and sharing

Local review: the artifact is served through a local Express server.
Publishing: the optional share command uploads to ht-ml.app, a third-party service.
Important: shares are public by default. Use --private or --password for protected access, and still avoid sensitive data unless appropriate.

Core CLI commands

Open or resume a review
npx -y lavish-axi <html-file>
Wait for feedback
npx -y lavish-axi poll <html-file>
Export one portable HTML file
npx -y lavish-axi export <html-file> --out <path>
End the session
npx -y lavish-axi end <html-file>

You normally do not need to type these yourself—Codex uses them as part of the skill workflow.
