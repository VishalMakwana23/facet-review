Implementation baseline · v0.4

Build locally. Prove the advantage. Then deploy for everyone.

Facet becomes a credible Lavish alternative by separating the compact artifact protocol from the polished review host. The local CLI ships first; self-hosting and secure collaboration arrive only after measurable product proof.

03 · Deployment topology

Cloud is an adapter, not a dependency.

The same versioned artifact and event model powers local, self-hosted, and managed operation. This keeps users portable and the MVP small.
